# 🧠 Ethical Information Display Project

This project explores how much information a website can ethically access through standard HTML and browser APIs nothing hidden, nothing invasive.

It’s built purely for educational and transparency purposes, showing visitors what their browser naturally shares when loading a web page. The goal is to raise awareness about digital privacy, not to collect or misuse anyone’s data.

I don’t encourage or support any form of grabbing, tracking, or doxxing. All examples are strictly ethical demonstrations meant to help developers and users understand web data flow in a safe and responsible way. :)

In simple terms:
This isn’t about spying it’s about showing how websites work under the hood, and how to protect yourself by knowing what’s visible.
